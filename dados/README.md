# Catálogo estruturado

`inventario.json` reúne *candidatos* de termos, não uma afirmação de existência como objeto API nem suporte no OCP 4.22. Cada candidato deve ser classificado com: `classe`, `api_group`, `kind`, `scope`, `plataforma`, `versao`, `status`, `fontes`, `slug_verbete`, `relacoes`. Gerar índices a partir dos verbetes efetivamente validados, preservando termos sem API (componentes e conceitos).
