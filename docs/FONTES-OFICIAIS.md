## Fontes das próprias documentações (para conferir conteúdo e versão)

- [Kubernetes API Conventions](https://github.com/kubernetes/community/blob/master/contributors/devel/sig-architecture/api-conventions.md): spec/status, kinds, conditions.
- [`kubernetes/website`, branch `release-1.35`](https://github.com/kubernetes/website/tree/release-1.35/content/en/docs): fonte do kubernetes.io na versão usada pelo OCP 4.22.
- [`openshift/openshift-docs`, branch `enterprise-4.22`](https://github.com/openshift/openshift-docs/tree/enterprise-4.22): fonte AsciiDoc da documentação do OCP 4.22.

**Regra de versão:** o OCP 4.22 usa **Kubernetes 1.35** (release notes 4.22, "About this release"). Conteúdo do kubernetes.io mais recente que a 1.35 não vale automaticamente para o OCP 4.22.

**Quando as URLs publicadas não puderem ser abertas** (rede restrita), conferir nos fontes acima, citar o caminho do arquivo e registrar a pendência em [TERMOS-A-VALIDAR](TERMOS-A-VALIDAR.md).

Outras fontes como CNCF, OpenShift GitHub e projetos de código aberto complementam, mas não substituem a referência mais próxima da versão. Consultar datas em cada revisão.
